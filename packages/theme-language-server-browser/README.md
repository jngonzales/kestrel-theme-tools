# `@kestrel/theme-language-server-browser`

This is the Browser wrapper of the runtime-agnostic [`@kestrel/theme-language-server-common`](https://npm.im/@kestrel/theme-language-server-common) package. It does not come with batteries included and assumes you know what you're doing.

Presumably for use in CodeMirror along with [`@kestrel/codemirror-language-client`](https://npm.im/@kestrel/codemirror-language-client).

See the [@kestrel/theme-language-server-common README](../theme-language-server-common) for more details.
